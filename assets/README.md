# Source images

Full captures the `public/tile-*.webp` cards are generated from. Kept out of
`public/` so they are not served — only the composed tiles are.

`screenshot-voting-app.webp` is **redacted**: colleague names and photographs
are obscured in the file itself. Do not replace it with a raw capture.

Tiles are 1096x438 (2x the 5:2 card band), every source placed at the same
0.91x scale so the UI reads at a consistent size across all four cards.
